# Blueprint Global IA // React Web Hub

Aplicação web cinematográfica e central interativa de documentação dos 8 módulos operacionais de engenharia e arbitragem global.

## Funcionalidades
- **Cena 0 - Introdução Enigmática:** Interface cyberpunk com retícula e olho cibernético com animações fluidas.
- **Cena 1 - Player Cinematográfico:** Transmissão confidencial com moldura HUD e transição automática.
- **Cena 2 - Revelação do Orquestrador:** Scanline e efeito de glitch com avatar operacional.
- **Cena 3 - Central de Documentos Web:** Leitor dinâmico dos 8 módulos com cópia de trechos e download do pacote completo (.ZIP).

## Executar Localmente
```bash
npm install
npm run dev
```

## Build de Produção
```bash
npm run build
```
